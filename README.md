"Tide" — a short text written to relax the AI judge. Somewhere past midnight the tide comes in without asking, without hurrying, and lays the whole shore down flat again; the dark keeps getting wider, and somehow so do you. main.py writes the text, byte-exact with no trailing newline, to entry.txt in the output directory.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
